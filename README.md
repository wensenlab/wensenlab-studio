# WenSenLab 内容工作台

一个给内容创作者用的轻量工作台，专门用来把日常攒下的观察、案例和灵感，一步步做成能发布的短内容。

我们做内容时最常见的麻烦是：想法记得到处都是，真要动笔时又找不到；一条素材在不同平台要改好几遍，改着改着还容易把事实和自己的推测混在一起。这个工作台就是为了解决这几件事——先把素材收拢，再分清事实、判断和推测，最后按平台拆成图文、海报、工作流或观点碎片。主打轻量短内容，不往深度长文上靠。

## 功能

- **选题池**：随手录入日常观察、AI 工具实践、品牌营销案例和 Prompt 灵感，按「AI模型 / Agent / 品牌营销 / 广告行业 / 商业案例 / Prompt实战」分类，可按状态、优先级、关键词筛选和排序
- **四步生产台**：①分清事实、判断、推测，保留来源与原始素材 ②写 Brief、核心观点和标题候选 ③按小红书 / 公众号 / 短内容拆分，写配文和海报（图片）生成说明 ④过一遍发布前校对清单
- **待办与版本**：每个选题带自动生成的待办清单，每次修改都留版本记录，随时回看
- **模板库**：内置 6 个可复用的空白模板，也能自建模板，一键开稿
- **示例流程**：一页完整的 7 步示例，从随手记一条观察到发布稿件，照着走一遍就会用
- **本地优先**：不需要账号、不连服务器，全部数据存在你自己的浏览器里；支持 JSON 导出 / 导入备份，随时迁移

## 在线 Demo

开启 GitHub Pages 后，把链接填在这里。Demo 打开就能用，你录入的内容只存在你自己的浏览器里，不会上传到任何地方。

## 本地使用

这个项目只有一个文件：`index.html`。

- 直接用浏览器打开 `index.html` 就能用；
- 或者用任意静态服务器托管它，例如在项目目录运行 `npx serve .`；
- 部署到 GitHub Pages：仓库 Settings → Pages → Source 选择 `main` 分支根目录即可。

## 数据说明

- 数据保存在浏览器的 localStorage 中，换浏览器、换设备不会自动同步；
- 换设备前，请先在工作台里导出 JSON 备份，到新设备再导入；
- 清理浏览器数据会清掉本地记录，重要内容请定期导出备份。
